Privacy · 隐私权政策

你的数据，我们怎么处理

Last updated: 26 September 2026

这份政策用白话写，因为它本来就该让人看得懂。它说明大道至简网站 （含「内耗状态自我评估与自洽引导工具」）会搜集哪些数据、为什么搜集、 交给了谁、留多久，以及你随时可以怎么要回或删除。

数据的搜集者是本站主理人简家旗（以下称「我们」）。有任何疑问， 写信到 dadaoissimple@gmail.com， 我们会亲自回复。

告知事项一览（个人数据保护法第八条）

依《个人数据保护法》第八条，我们在搜集你的个人数据时应告知下列事项。以下是摘要，细节见后面各节。

  • 搜集者名称：大道至简主理人简家旗（云南好物订单的收款户名为「嘉礼慕华舖」）。
  • 搜集目的（法务部公告之特定目的）： 〇六九 契约、类似契约或其他法律关系事务；〇九〇 消费者、客户管理与服务； 一四八 网络购物及其他电子商务服务；一三五 资（通）讯服务；一三六 资（通）讯与数据库管理。 详见第三节。
  • 个人数据类别：C001 辨识个人者（姓名、手机、电子邮件、地址或取货门市、LINE ID）； C002 辨识财务者（汇款帐号末五码，仅在你回复付款时提供）；以及你主动填写的内容（来信、测验结果、订购商品、送礼卡片）。 详见第一节。
  • 利用期间：依各项目的保存期限，见第五节；期满删除。
  • 利用地区：台湾，以及第四节所列服务供应商的主机所在地（美国等台湾境外地区）。
  • 利用对象：本站主理人，以及第四节所列、为完成服务所必要的服务供应商与物流业者。
  • 利用方式：在搜集目的范围内，以电子或纸本方式处理与利用，例如寄送确认信与出货通知、打印出货单、交寄包裹。
  • 你的权利与行使方式：查找、阅览、制给拷贝本、补充或更正、停止搜集处理利用、删除，见第六节。
  • 不提供的影响：是否提供由你自由决定。但若不填写表单上的必填字段， 我们将无法回复来信、寄送指南，或完成订单与寄送。

一、我们搜集哪些数据

只有你主动填写时才会有数据进来。没有填任何表单就离开的访客，我们手上不会有你的任何个人数据。

写信给我们（连系表单）

  • 你填的称呼、电子邮件、主题与内容
  • 送出的时间、从哪一页送出
  • 一段由 IP 地址算出、无法还原的哈希值，只用来挡短时间内大量送出；我们不保存你的 IP 地址

送出后会有一封收信确认寄到你填的信箱，里面附上你写的内容。之后的往来，就是我们回复你的信。

领取《7 天能量自洽复位指南》

  • 你填的称呼与电子邮件
  • 当次测验的结果：能量原型、内耗熵值、六位答案码、送出时间

送出后我们会寄一封确认信给你，里面有指南的下载链接与你这次的结果摘要。 就这一封，之后不会再寄任何信件——我们不做电子报。 留下信箱的用途，是让我们知道谁拿了指南，以及在你来信询问时能对得上你的测验结果。

购买深度报告（自洽跃迁破局手册）

  • 付款由 Gumroad 处理。我们不会接触、也无法看到你的信用卡或金融帐户数据。
  • 我们会保存：Gumroad 的授权码、你的测验分数与原型、以及为你生成的报告内容

报告会保存下来，是为了让你日后能再打开同一个链接重看，也让我们在你提出退款或疑问时查得到。

订购云南好物（选购页）

  • 订购人的姓名、手机、电子邮件，选填的 LINE ID 与备注
  • 取货数据：宅配地址或超商门市；送礼时另有收件人的姓名、手机与你写的卡片内容
  • 订购的商品、金额、付款方式、出货状态与物流追踪号码
  • 与连系表单相同的 IP 哈希值，只用来挡短时间内大量送出

这些数据只用在这张订单：确认订单与付款、包装寄送、寄订单确认与出货通知、有问题时联系你。 不用来寄行销消息，也不提供给与寄送无关的人。 送礼时，收件人的数据由你提供，请先让对方知道会有一份礼物寄过去。

预约云南安宁幸福之家

  • 预约人的姓名、手机、电子邮件、微信或 LINE ID
  • 想入住的月份与日期、人数、套房数，选填的同行朋友称呼、这趟想要的旅居方式与你想先告诉我们的话
  • 确认的入住日期、金额、付款方式与付款状态
  • 与连系表单相同的 IP 哈希值，只用来挡短时间内大量送出

这些数据只用在这次预约：确认日期、收款、安排入住、寄预约确认与付款信息、有问题时联系你。 不用来寄行销消息，也不提供给其他人。同行朋友的称呼由你提供，请先让对方知道。

我们不会搜集的东西

身分证字号、生日、性别、就医纪录，一律不收。测验题目本身也不会问这些。地址只有在你订购云南好物时才会填，而且只用来寄送；电话只用来联系订单或预约。

二、留在你自己设备上的数据

测验结果会存在你浏览器的 localStorage 里，这样你去结帐再回来时结果还在。 这份数据只留在你的设备上，不会上传到我们这里；清除浏览器数据就会消失。

在云南好物选购页，你放进订单的商品与数量也会存在浏览器的 localStorage，让你刷新页面后不必重选； 送出订单后就会清空。这份数据同样只留在你的设备上。

本站目前不使用 cookie，也没有安装任何广告追踪工具。品牌站、云南好物选购页与安宁幸福之家页使用 Cloudflare Web Analytics 统计浏览量（见下方「四」），它不使用 cookie、不在你的设备上存任何数据，也不追踪个别访客。

三、我们为什么搜集，依据是什么

  • 回复你的来信——依据你的同意（你主动写信给我们）。
  • 提供免费指南——依据你的同意。你给我们称呼与信箱，换一份指南；这是一次明确的交换。
  • 生成并保存你买的报告——为了履行你我之间的交易契约。
  • 处理云南好物订单——为了履行买卖契约：没有姓名、电话与地址，东西寄不到你手上。
  • 防止滥用（速率限制、授权码验证）——基于我们的正当利益：生成报告需要成本，必须挡住自动化的滥用。

我们不会把你的数据拿去做广告投放、也不会卖给任何人。这一点没有例外。

四、我们把数据交给谁

我们是很小的团队，仰赖几个第三方服务。以下是全部，以及各自实际拿到什么：

  • Cloudflare（Workers、D1 数据库）——连系表单的内容与云南好物的订单存放在这里。 服务器位于美国等台湾境外地区。
  • Google（Gmail）——连系表单的通知与收信确认、云南好物的订单确认与出货通知，由主理人的 Gmail 寄出，信件因此也会留在 Gmail 里。
  • 物流业者（宅配或超商）——寄送云南好物时，只提供收件人姓名、手机与地址或门市，这是把东西送到的必要数据。
  • Google（Google 试算表、Apps Script）——领取指南时填的称呼、信箱与测验结果存放在这里。 服务器位于美国等台湾境外地区。
  • GitHub Pages——网站主机。与所有网站主机一样，会产生包含 IP 地址的访问纪录。
  • Cloudflare Web Analytics——用在品牌站（繁、简体）、云南好物选购页与安宁幸福之家页，统计有多少人来、看了哪一页、从哪个网站连过来、所在国家与设备类型。 不使用 cookie、不做跨网站追踪，也不会把你填的任何数据送过去；我们只看得到整体的统计数字，看不到个别访客。
  • LINE Pay 与银行——云南好物的付款由你直接在 LINE Pay 或网络银行完成。 我们只看得到收款纪录（金额、时间、付款人名称或帐号末五码），不会接触你的信用卡或帐户密码； 付款数据由 LINE Pay 与银行依其隐私政策保管。
  • LINE 官方帐号——如果你通过 LINE 官方帐号 @617aipgs 与我们联系，对话会存在 LINE 的服务中，适用 LINE 的隐私政策。
  • Gumroad——付款处理与授权码发放。你的付款数据由他们保管，适用他们的隐私政策。
  • DeepSeek——生成你的深度报告。 送出去的只有测验分数与能量原型；不包含你的姓名、电子邮件或任何可直接识别你的数据。 DeepSeek 为中国公司，这段处理会在台湾境外进行。如果你不希望数据被送到境外处理， 请不要购买深度报告——免费指南与测验本身完全不会用到这项服务。

五、保留多久

  • 来信内容：回复完成后保留两年，以便回溯先前的对话。
  • 指南名单：保留到你要求删除为止。
  • 购买纪录与报告内容：自购买日起保留五年（配合税务与交易纪录的保存需要）。
  • 云南好物订单：自下单日起保留五年（配合税务与交易纪录的保存需要）；期满删除。
  • 安宁幸福之家预约：自送出日起保留五年（配合税务与交易纪录的保存需要）；没有成行的预约也一样，期满删除。

你随时可以要求提前删除，我们会在十天内完成并回信告知，法令另有规定必须保存者除外。

六、你的权利

依台湾《个人数据保护法》第 3 条，你就我们持有的个人数据享有下列权利：

  • 查找或请求阅览
  • 请求制给拷贝本
  • 请求补充或更正
  • 请求停止搜集、处理或利用
  • 请求删除

若你位于欧洲经济区或英国，依 GDPR 你另有数据可携、限制处理、反对处理， 以及随时撤回同意的权利（撤回不影响撤回前的处理），并可向你所在地的数据保护主管机关提出申诉。

行使方式很简单：写信到 dadaoissimple@gmail.com， 用你当初填写的那个信箱寄出即可，我们会在十个工作天内处理。 不需要说明理由，也不会因此影响你已经买到的东西。 也可以通过 LINE 官方帐号 @617aipgs 提出； 为了确认是你本人，我们可能会请你提供订单编号或当初填写的手机号码。

依个资法第十条、第十一条，若有法定不得提供或必须保存的情形（例如税务法规要求保存的交易纪录）， 我们会说明理由。法律规定的处理期限是收到请求后十五日内（必要时可延长十五日并告知原因），我们通常在十个工作天内就会完成。 如果你认为我们处理个人数据的方式不当，也可以向个人数据保护主管机关申诉。

七、数据安全

全站以 HTTPS 传输；API 密钥只存在服务器端的设置档，不会进入版本控制，也不会出现在网页原代码里； 存放名单的试算表与来信数据库仅限主理人访问（数据库的管理页需要密码）。

但我们不会夸口说绝对安全——没有任何在线服务可以这样保证。 我们的做法是只收必要的数据、不收敏感数据，把风险本身降到最低。

万一发生个人数据被窃取、泄漏、窜改或其他侵害，我们会依个资法第十二条，在查明后以电子邮件、 LINE 或其他适当方式尽速通知受影响的你，说明发生了什么事，以及我们采取的处理措施。

八、未成年人

本站的内容与服务不以未满 16 岁者为对象。若你未满 16 岁，请在家长或监护人同意后再填写任何表单。 若我们发现误收了未成年人的数据，会主动删除。

九、这份政策的变更

若搜集方式有实质变动（例如加装分析工具、添加第三方服务），我们会先更新这一页并修改上方的日期， 再让变更上线。重大变更会另行在网站上说明。

十、联系我们

任何关于隐私的问题、要求或抱怨，请写信到 dadaoissimple@gmail.com， 或加 LINE 官方帐号 @617aipgs。 我们亲自回复，不是自动客服。

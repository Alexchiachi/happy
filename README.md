# 幸福餐桌·行為藝術系統
## Happiness Dining Table × Behavioral Art

> 天麻不再是農產品，而是「幸福的物質承載」
> 
> *From commodity to cultural symbol | From consumption to co-creation*

---

## 📖 系統概述

幸福餐桌是一個以**承德天麻**為核心載體的行為藝術項目，通過季節仪式、風土敘事、用戶共創，將傳統農產品轉化為文化符號，實現「從產品銷售到情感溢價」的商業飛輪。

### 核心創新
- **去功效化**：不宣傳「增強記憶、安神」，而強調風土故事與仪式體驗
- **文化符號化**：每場行為藝術賦予天麻新的視覺與情感意象
- **全年價值鏈**：四季循環仪式，持續蓄客與復購
- **用戶身份躍遷**：從消費者→共創者→品牌代言人

---

## 🌿 天麻五維定位

### 一、本質定義：風土印記的物質化

**轉變邏輯**
```
傳統天麻          →          幸福餐桌的天麻
藥用農產品                    文化情感符號
功效導向                      風土敘事優先
按斤售賣                      帶溫度的禮物
```

**核心轉變**
- 風土優先於功能：承德松林四季節氣、手工工藝 = 真正價值內核
- 溯源證據鏈：數字化種植履歷（土壤、光照、採摘記錄）替代檢驗報告
- **一句話定義**：天麻 = 承德松林的風土印記 + 幸福餐桌的仪式媒介 + 用戶可帶走的「幸福片段」

---

### 二、文化符號化：行為藝術的賦能

每場仪式都為天麻創造新的文化意象，形成排他性競爭力。

| 季節 | 視覺符號 | 感官記憶 | 護城河 |
|:---|:---|:---|:---|
| **夏** | 桑樹下紫色手染午宴 | 紫色+松脂味+泥土溫度 | 競對無法複製的仪式場景 |
| **秋** | 採挖敬土感恩祭 | 滿手泥土+豐收喜悅 | 挖麻時的合照=共創證據 |
| **春** | 破土手植仪式 | 嫩芽生長的期待感 | 用戶變身「天麻父母」 |
| **冬** | 窖藏年度幸福志發布 | 陳年天麻的溫暖滋補 | 全年回顧+下年預售 |

**命名系統演進**
- ❌ 傳統：「承德天麻 500g」
- ✅ 優化：「靜山麻·夏季紫染限定版」「醒和·天麻安炖」「豐收紀念版·秋挖天麻」

### 三、商業價值：文化溢價飛輪

白皮書證實了天麻在多個收入節點的核心作用。

#### 收入結構
| 節點 | 天麻參與形式 | 預期價格 | 年度潛力 |
|:---|:---|:---|:---|
| **參演凭证** | 現場品嚐鮮天麻炖品 | ¥398/人 | 核心體驗入口 |
| **衍生品復購** | 炖品料包、季節限定禮盒 | ¥128-228 | 40%-60% 回頭客 |
| **B端授權** | 高端餐廳仪式脚本+原料訂單 | 授權費+訂單 | 規模化複製 |
| **農產品提價** | 包裝為「幸福餐桌紀念版」 | +30%-80% 溢價 | 銷量不降反升 |

#### 關鍵數據
- 單季天麻相關收入（衍生品+原料供應）：**佔閉環總收入 40%-60%**
- 提價後銷量：**不降反升**（用戶購買的是「親眼見證的記憶」）
- 用戶復購率：遠高於傳統農產品客戶

**底層邏輯**：場景稀缺性 → 情緒價值 → 無法被比價

### 四、用戶體驗：從消費者到共創者

幸福餐桌參與者不是顧客，而是**行為藝術的共創者**。

#### 體驗四步曲

```
參演前                          現場挖麻
↓                              ↓
收到編號邀請函 ←────── 期待心理 ────→ 泥土沾滿手指
內含天麻故事與仪式預告         摄影師捕捉「我與天麻」合照
                              ↓
      ↑←────────────── 共創證據 ─────→↓
      │                              仪式化烹飪
帶走紀念                    用戶親手參與切片、入鍋、撒鹽
      │                              松風中飄香
麻布袋裝烘乾天麻片          ↑
行為記錄卡+松枝            │
掃碼復購通道               │
      ↑←────────── 帶走紀念 ─────────┘
```

#### 身份沉澱
- 成為「**天麻父母**」（春季手植仪式參與者）
- 名字被列入年度「幸福志」
- 享有下一季預售優先權
- 復購率↑ 推薦率↑ LTV↑

### 五、季節仪式：四季循環價值鏈

#### 全年節奏規劃

| 季節 | 仪式名稱 | 天麻形態 | 用戶行動 | 商業目標 |
|:---|:---|:---|:---|:---|
| **🌱 春** | 破土仪式·手植天麻苗 | 天麻種苗、養生料包 | 親手種下，成為「父母」，全程接收生長記錄 | 蓄客、身份認同 |
| **🌞 夏** | 桑樹下的紫色手染午宴 | 鮮天麻（現挖現炖）、手工料包 | 現場挖麻、共餐、獲得參演凭证與合照 | 體驗轉化、記憶銘刻 |
| **🍂 秋** | 採挖仪式·敬土感恩祭 | 鮮挖天麻、冬儲料包、秋天手冊 | 參與採挖、帶走「豐收紀念版」天麻 | 高端復購、禮贈市場 |
| **❄️ 冬** | 窖藏仪式·年度幸福志發布 | 陳年天麻、冬季滋補包、紀錄片 | 回顧全年故事、預售下年禮盒 | 蓄客下年、沉澱品牌故事 |

#### 價值邏輯
- **非季節性集中售賣**：天麻四季都有故事、有形態、有觸點
- **環型蓄客**：每季仪式為下季預售蓄客（夏季參與者→秋季復購→冬季預售→春季體驗）
- **季節性稀缺**：鮮天麻僅現身兩週 → 紧迫感 + 收藏心理

## 📚 電子書出版工具鏈

本 repo 另附一套獨立的電子書上架前檢查工具，供白皮書與衍生出版品發行使用。
涵蓋 **英文 / 繁體中文 / 簡體中文 / 日文 / 韓文** 五語版本，
對齊 Amazon KDP、Apple Books、Google Play Books、Kobo 的上架規則。

```bash
python3 -m epubqa check book.epub                    # 檢查
python3 -m epubqa fix book.epub -o book-fixed.epub   # 自動修正
python3 -m epubqa batch dist/ -o reports/            # 多語版一致性比對
```

- [工具說明](./docs/EPUBQA.md) — 指令、檢查類別、設計原則

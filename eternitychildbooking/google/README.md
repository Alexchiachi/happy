# 用 Google 試算表收預約（推薦）

免費、不用主機、不用外掛。預約送出後會同時：

1. 在 Google 試算表新增一列（含「狀態」欄，可直接當後台管理）
2. 寄一封通知信到 `ahanamita88888888@gmail.com`（按「回覆」就是回信給客人）
3. 依客人選的語言，自動回一封確認信給客人（中／英／日／韓）
4. **把已成立的時段回報給預約頁，讓其他客人看到那個時段已被約走**

資料只經過你自己的 Google 帳號，不經任何第三方服務。

---

## ⚠️ 已經部署過的話，改了程式要重新部署

Apps Script **不會**因為你存檔就更新線上的版本。每次改完程式都要：

`部署 → 管理部署作業 → 右上角鉛筆（編輯）→ 版本選「新版本」→ 部署`

用「管理部署作業」的方式更新，`/exec` 網址**不會變**，不用再改一次程式碼裡的設定。
如果改成「新增部署作業」就會拿到另一組網址，那才需要回去更新 `endpoint`。

---

## 部署步驟（約 5 分鐘）

**1. 建立試算表**
到 [sheets.new](https://sheets.new) 開一個新的 Google 試算表，取名例如「永恆之子預約紀錄」。

**2. 貼上程式**
在該試算表點 `擴充功能 → Apps Script`，把預設的程式碼全部刪掉，
改貼上本資料夾的 `booking-sheet.gs` 全部內容，按存檔（💾）。

**3. 部署成網頁應用程式**
右上角 `部署 → 新增部署作業`：

| 欄位 | 選擇 |
|:---|:---|
| 類型（左上齒輪） | 網頁應用程式 |
| 執行身分 | **我**（你自己的帳號） |
| 誰可以存取 | **所有人** |

按「部署」。第一次會跳出授權畫面——選你的 Google 帳號，
看到「Google 尚未驗證這個應用程式」時點 `進階 → 前往「未命名的專案」（不安全）`，
再按「允許」。這是你自己寫的程式，授權對象是你自己。

**4. 複製網址、貼進設定**
部署完成後會給你一段像這樣的網址：

```
https://script.google.com/macros/s/AKfycb.................../exec
```

打開 `index.html`（或 `standalone.html`），搜尋 `endpoint`，改成：

```js
endpoint: 'https://script.google.com/macros/s/AKfycb.................../exec',
```

存檔上傳，完成。

## 確認有沒有成功

**先測部署**：把 `/exec` 網址直接貼到瀏覽器打開，看到這樣就對了：

```json
{"ok":true,"service":"永恆之子整椎中心","sheet":"預約紀錄"}
```

**再測防撞單**：在網址後面加上 `?action=slots` 打開，會看到已被預約的時段：

```json
{"ok":true,"taken":{"2026-09-30":[[540,600]]}}
```

數字是從當天 00:00 起算的分鐘數，540 = 09:00、600 = 10:00。試算表沒資料時是 `{}`。

**再測整條流程**：到預約頁自己送出一筆假預約，然後檢查

- 試算表有沒有多一列
- 信箱有沒有收到「[新預約 ECC-…]」
- 你填的那個客人信箱有沒有收到確認信

三個都有就完成了。接著重新整理預約頁，剛剛約掉的那個時段應該已經變成反灰。
測試完把試算表那一列刪掉即可。

> **要放掉某個時段**：不用刪列，把「狀態」欄改成「已取消」就好，
> 那個時段會立刻重新開放預約，紀錄也還留著。

## 收不到的話，照這個順序查

| 症狀 | 原因與解法 |
|:---|:---|
| `/exec` 網址打不開或要求登入 | 部署時「誰可以存取」沒選「所有人」。重新部署一次 |
| 試算表沒新增列 | `endpoint` 沒貼對，或貼成 `/dev` 結尾的網址（要用 `/exec`） |
| 試算表有列、但沒收到信 | Gmail 每日寄信有配額上限；也看一下垃圾信匣 |
| 改了程式沒生效 | Apps Script 要重新「部署 → 管理部署作業 → 編輯 → 版本改為新版本」才會更新 |

送出失敗時，預約頁會**自動退回**「開啟客人的信箱程式」那條路，
所以就算後端出問題，預約也不會直接消失。

---

## 防撞單是怎麼運作的

預約頁在開啟時、以及客人進到「選擇時間」那一步時，會向 `?action=slots` 讀回
已成立的時段（30 秒內不重複查詢），再把會重疊的時段鎖住。

判斷是「區間重疊」而不是「開始時間相同」——例如別人約了 09:00–10:00，
那麼 09:30 開始的 40 分鐘療程（做到 10:10）也會一併鎖住。

如果 Google 那邊暫時連不上或回傳異常，預約頁會照常運作，只是暫時看不到
別人的預約。這是刻意的取捨：寧可偶爾撞單，也不要讓客人完全無法預約。

# 圖片資料夾

把照片放進這個資料夾，網頁就會自動顯示。

## 中心實景照片（四張）

檔名**必須**是這四個，網頁才找得到：

```
photo-1.jpg
photo-2.jpg
photo-3.jpg
photo-4.jpg
```

| 項目 | 建議 |
|:---|:---|
| 形狀 | 正方形或接近正方形（網頁會裁成正方形顯示，主體請放中央） |
| 尺寸 | 寬 800–1200 px |
| 檔案大小 | 每張 300 KB 以內，越小開得越快 |
| 格式 | JPG |

**`photo-1.jpg` 會同時當作社群分享的預覽圖**——把預約網址貼到 LINE、
Facebook 時會顯示這張，所以第一張建議挑最能代表中心的那張。

沒放上去的照片會自動略過，四張都沒有時整個區塊會隱藏，不會留下空白。
想少放幾張也可以，例如只放兩張就會顯示兩張。

## TWQR 收款條碼（選填）

把櫃檯的收款條碼存成 `twqr.jpg` 放進來，再到 `config.js` 把
`qrImage` 設成 `'assets/twqr.jpg'`，確認頁就會顯示條碼。

## 怎麼上傳（不用安裝任何軟體）

1. 在 GitHub 打開這個資料夾
2. 右上角 `Add file` → `Upload files`
3. 把四張照片拖進去（檔名先改好）
4. 下方按 `Commit changes`

上傳後約一兩分鐘網站會自動更新，記得強制重新整理（Ctrl+Shift+R／Cmd+Shift+R）。

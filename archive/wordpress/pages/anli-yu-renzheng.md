# 案例與認證

用證據說話。幸福不是形容詞，是可以被體驗、被傳遞、被實現的價值。

## 證據，是幸福最有力的語言

2017 年——稻田裡的餐桌計畫成為亞洲第一家通過英國 Social Value International（SVI）SROI 認證的農業社會企業；完整報告 130 頁（[PDF 下載](https://hii.hdv.mybluehost.me/wp-content/uploads/2026/08/SROI-of-DITFP-2017.6.19-final_0718.pdf)），評估 2013–2016 四年社會影響，結果 SROI 值 4.4——每投入 1 元新台幣，創造 4.4 元社會價值（[台灣社會價值學會・SVI 認證報告列表](https://socialvaluetw.easy.co/pages/taiwan-reports)）。

2012 年至今——稻田裡的餐桌逾兩百場，從台灣到雲南、貴州、香港，影響數萬都市人與數百位農漁民。

媒體與講學——湖南衛視《鄉村合夥人》台灣農業文化旅遊專家、長江商學院 EMBA 台灣文創行講師；商業週刊、遠見雜誌等百餘篇報導。

企業與地方合作——企業 ESG 體驗（雲南農場）、貴州文旅節慶、香港與台灣各地餐會、地方創生與品牌授權。

## 常見問題

稻田裡的餐桌辦過多少場？

2012 年至今逾兩百場，從台灣到雲南、貴州、香港，影響數萬都市人與數百位農漁民。

SROI 認證是什麼？

SROI 是社會投資報酬評估，用貨幣衡量專案創造的社會價值。2017 年，稻田裡的餐桌計畫成為亞洲第一家通過英國 Social Value International 認證的農業社會企業，評估 2013–2016 四年，SROI 值 4.4——每投入 1 元新台幣，創造 4.4 元社會價值。

企業可以怎麼與簡家旗合作？

企業 ESG 體驗、幸福文化顧問、高階主管一對一、員工幸福課、地方品牌與幸福餐桌 IP 授權——先談清楚需求，再設計現場。

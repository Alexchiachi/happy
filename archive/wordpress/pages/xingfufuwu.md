# 三條路徑，\
對應三種位置。

從 2012 年稻田餐桌至今，我和企業家、團隊、一個個具體的人一起工作，走過台灣、香港、中國大陸。

以下每條路徑對應不同的合作形式與深度——看哪一條適合你現在所在的位置。

01

### 企業幸福顧問

你的企業文化，從你開始。

企業家的狀態，是整個組織生態的根。為企業家與高階主管提供一對一幸福顧問服務，以道家智慧融合現代管理，協助你重新定義工作與生命的關係，從而帶動整個組織的正向轉化。

適合對象

感覺失去動力的創業者 · 想深化企業文化的執行長 · 尋求人生轉折的高階主管

形式

一對一長期顧問關係

02

### 生命裡的幸福課

從食衣住行出發，找回生命的本質。

以道家哲學為根，從日常細節重新感知幸福。透過雲南深度沉浸課程，在大地的節奏中找回屬於自己的生命意義。

課程形式

小組沉浸式 · 雲南大理 · 5–7 天

適合對象

想找回生活平衡的現代人 · 尋求內在轉化的旅行者 · 高壓工作後需要重整的創業者

03

### 幸福餐桌 IP 授權

台灣最早的產地餐桌，開放品牌授權合作。

稻田裡的餐桌，2012 年由簡家旗在台灣發起，是台灣「從產地到餐桌」理念的先驅計畫，走過雲南、台東、花蓮等地，深耕逾十二年。現以品牌授權形式開放合作。

合作形式

場地授權 · 品牌聯名 · 活動共創 · 顧問規劃

適合對象

農場主 · 餐廳品牌 · 旅宿業者 · 地方創生團隊

※

每月只開放極少數名額。

## 四種合作形式

從單次諮詢到長期企業顧問陪跑，依你現在的位置與需求深度選擇合作層次。

方案一

幸福啟程諮詢

NT$50,000 起

單次一小時線上諮詢

包含

- 一對一線上諮詢（60 分鐘）

- 幸福狀態評估問卷

- 書面建議摘要報告

方案二

生命裡的幸福課

NT$500,000 起

雲南 5–7 天沉浸課程

包含

- 一對一線上諮詢（60 分鐘）

- 雲南深度沉浸課程（5–7 天）

- 個人幸福行動計畫

- 課後 30 天線上支持

方案三

幸福 IP 授權規劃

NT$1,000,000 起

需先預約評估面談

包含

- 一對一線上諮詢（60 分鐘）

- 雲南深度沉浸課程

- 幸福 IP 規劃與設計

- 品牌授權框架建立

- 3 個月顧問陪跑支持

方案四

企業幸福顧問

NT$5,000,000 起

需評估面談，一年起合約

包含

- 一對一線上諮詢（60 分鐘）

- 雲南深度沉浸課程

- 幸福 IP 規劃與設計

- 企業幸福 IP 落地創造

- 長期企業顧問合約（一年起）

- 高管幸福工作坊（含整個團隊）

以上為起始報價，實際費用依合作範圍、時長與客製化程度調整。所有方案均需先透過初步諮詢評估合作適配性。如有任何疑問，歡迎直接聯絡我們。

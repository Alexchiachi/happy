## 商品描述（Description）

```
你已經看過自己的分數了。

那個數字不是評分，是一次測量——測量你的能量在流出去，而不是在累積。
現在的問題不是「我夠不夠努力」，而是：它從哪裡漏出去的？該從哪裡開始堵？

這份手冊會回答這兩個問題。它不是一份誰都適用的通用建議，
而是依你的能量原型、三維度分數與瓶頸維度，當場為你生成的。
換一個人來測，拿到的會是完全不同的一份。

---

它的視角來自耗散結構理論。

普里高津（Ilya Prigogine）發現：一個開放系統必須持續與外界交換能量、引進負熵，
才能維持自己的秩序與形狀；一旦封閉起來，它就必然走向熵增、均質，最後塌縮。

人也是這樣運作的。內耗不是你的性格缺陷，也不是意志力不足——
它是系統封閉之後的必然結果。所以破局的方向從來不是繼續壓榨自己，
而是重新把系統打開。

---

你會拿到什麼

· 一份 13 到 15 頁的完整手冊，五個章節：
  一、你此刻的系統狀態——描述你的能量如何流動、又如何流失
  二、耗散路徑拆解——具體指出能量在哪幾個環節漏掉，扣住你最低的那個維度
  三、負熵引入策略——關係、節奏、環境、身體四個面向各給具體做法
  四、四階段復位路線圖——每階段做什麼、多久、怎麼判斷已經完成、最常卡在哪
  五、情境腳本——被臨時交辦、深夜訊息、腦中重演、卡住無法開始，
      每個場景給你當下可以說的原句與可以做的動作

· 一段簡家旗寫給你的寄語

· 一段身心復位語音導引，依你的原型錄製，戴上耳機找一個不被打斷的十分鐘

· 一個永久連結。你可以隨時回來重看，也可以一鍵下載成 PDF 收著

---

這份手冊不是什麼

它不是心理諮商，也不是診斷。如果你的狀態已經明顯影響睡眠、飲食或日常功能，
請去找專業的人，那不是一份 PDF 能處理的事。

它不會讓你三天變成另一個人。真正的變化以週為單位發生，不是以天。
手冊裡的第一階段小到你今天就能開始——那是刻意的。

它也不是勵志讀物。裡面沒有一句「加油」或「相信自己」。
你要的不是鼓勵，是知道從哪裡下手。

---

適合現在買

· 你剛做完測驗，看到那個數字時心裡「咚」了一下
· 你不缺方法，缺的是知道哪一個方法對現在的你有用
· 你已經試過更自律，而它沒有用

先不要買

· 你還沒做測驗——手冊完全依你的分數生成，沒有分數就沒有意義
· 你正在等一個能替你做決定的人。這份手冊會給你路線圖，但走的人是你

---

怎麼拿到

購買後 Gumroad 會給你一組授權碼。回到測驗結果頁，把授權碼貼進去，
手冊會當場開始生成——你會看到章節一段一段長出來，大約一到兩分鐘。
生成完成後會給你一個永久連結，收在信箱或書籤裡都可以。

七天內不滿意，寫信給我們就退款，不需要說明理由。
```

## 上架前的設定備忘

- [ ] **開啟授權碼**：Gumroad 商品設定 → Checkout → 勾選「Generate a unique license key per sale」。
      **這一項沒開，整個解鎖流程就不會動**，因為外掛是靠授權碼驗證購買的。
- [ ] **取得 product_id**：商品建立後在網址或 API 頁面可查到，填進 WordPress 的
      `wp-config.php`：`define( 'INNER_FLOW_GUMROAD_PRODUCT_ID', '...' );`
- [ ] **商品網址**：填回 `inner-flow.html` 的 `#gumroadBtn` 的 `href`（目前是佔位網址）。
- [ ] **縮圖**：1280×720，沿用米白底＋暖棕的力場三角記號，不要放人像。
- [ ] **購買後導向**：設定成你的 WordPress 解鎖頁網址，讓買家不必自己找路回來。
- [ ] **退款政策**：Gumroad 的退款設定要與描述中的「七天」一致，兩邊不一致會有爭議。
- [ ] **定價**：目前描述沒有提到任何原價或折扣。若日後要做促銷，
      用 Gumroad 的 discount code，不要在描述裡寫一個從未存在過的原價。

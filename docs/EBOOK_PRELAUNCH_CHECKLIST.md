# 電子書上架前檢查清單
### Ebook Pre-Launch Checklist — en / 繁體中文 / 简体中文 / 日本語 / 한국어

適用平台：Amazon KDP、Apple Books、Google Play Books、Rakuten Kobo
最後校訂：2026-08

本清單分成三層：**A 阻擋上架**（不改就會被退件）、**B 品質**（會被讀者看見）、
**C 商業**（影響收入與曝光）。`epubqa` 工具能自動檢出其中大部分項目；
標示 🤖 者可自動檢查，標示 🔧 者可自動修正，其餘需人工判斷。

## 附錄一：為什麼 `lang` 屬性對中日韓特別重要

Unicode 的 **漢字統一（Han unification）** 讓中日韓共用同一批漢字碼位。
同一個碼位 U+9AA8（骨），在中文字型與日文字型中的字形不同：

```
沒有 lang 屬性  →  閱讀器用系統語言挑字型  →  日文書在中文系統上顯示中文字形
有 lang="ja"    →  閱讀器選日文字型        →  正確
```

讀者不會回報「這是 Han unification 問題」，只會覺得「這本書的字看起來怪怪的」，
然後給三顆星。這是投入產出比最高的一項修正——加兩個屬性就好。

**每一份**內容文件都要加，不只第一份：

```html
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:epub="http://www.idpf.org/2007/ops"
      lang="ja" xml:lang="ja">
```

書中若引用其他語言，該段落也要包起來：

```html
<p>他說：<span lang="ko">안녕하세요</span>，然後笑了。</p>
```

## 附錄二：繁簡轉換陷阱表

一個簡體字對應多個繁體字時，機器轉換會挑錯分支。
**產生的字元本身完全合法，拼字檢查抓不到**，只有讀者會發現。

| 簡 | 繁 | 錯誤範例 → 正確 |
|:-:|:---|:---|
| 干 | 干 / 乾 / 幹 | 干淨→**乾**淨、餅干→餅**乾**、才干→才**幹** |
| 后 | 后 / 後 | 以后→以**後**、然后→然**後**（皇后不變） |
| 里 | 里 / 裡 | 那里→那**裡**、心里→心**裡**（公里不變） |
| 面 | 面 / 麵 | 面條→**麵**條、面包→**麵**包（面孔不變） |
| 发 | 發 / 髮 | 頭發→頭**髮**、理發→理**髮**、發型→**髮**型 |
| 松 | 松 / 鬆 | 輕松→輕**鬆**、放松→放**鬆**（松樹不變） |
| 只 | 只 / 隻 | 一只→一**隻**（只有不變） |
| 准 | 准 / 準 | 准確→**準**確、標准→標**準**（批准不變） |
| 钟 | 鐘 / 鍾 | 鍾頭→**鐘**頭、分鍾→分**鐘** |
| 志 | 志 / 誌 | 雜志→雜**誌**、日志→日**誌** |
| 系 | 系 / 係 / 繫 | 關系→關**係**、聯系→聯**繫** |
| 制 | 制 / 製 | 制造→**製**造、制作→**製**作 |
| 复 | 復 / 複 / 覆 | 復雜→**複**雜、重復→重**複**、答復→答**覆** |
| 采 | 采 / 採 | 采訪→**採**訪、采用→**採**用（風采不變） |
| 历 | 歷 / 曆 | 日歷→日**曆**、農歷→農**曆**（歷史不變） |
| 尽 | 盡 / 儘 | 盡管→**儘**管 |
| 范 | 范 / 範 | 范圍→**範**圍（范僅用於姓氏） |
| 丑 | 丑 / 醜 | 丑陋→**醜**陋（丑角不變） |

`epubqa fix` 會依上表自動修正這些整詞替換。
**單字的簡→繁批次轉換則不會自動處理**——因為需要語意判斷，
工具只會報告位置交由人工處理，避免製造新的錯誤。

## 附錄四：上架前最終流程

```bash
# 1. 檢查（不修改）
python3 -m epubqa check book.epub

# 2. 先看會改什麼
python3 -m epubqa fix book.epub --dry-run

# 3. 自動修正
python3 -m epubqa fix book.epub -o book-fixed.epub

# 4. 人工處理剩下的錯誤，再檢一次
python3 -m epubqa check book-fixed.epub

# 5. 瘦身
python3 -m epubqa optimize book-fixed.epub -o book-final.epub

# 6. 官方 EPUBCheck 把關（Apple 以此為準）
python3 -m epubqa check book-final.epub --epubcheck epubcheck.jar

# 7. 五個語版一起比對
python3 -m epubqa batch dist/ -o reports/
```

**最後一步不能省：在真實裝置上翻過一遍。**
工具檢查不了「這句翻譯讀起來很怪」、「這張圖在電子紙上糊掉了」、
「這個換行讓標題斷在奇怪的地方」。至少測試：

- Kindle（電子紙，看灰階圖片與字型）
- iPhone / Android 手機（看最小螢幕的排版）
- iPad / 平板（看跨頁與圖片）
- 各語版都要至少開一次，特別確認**漢字字形正確**

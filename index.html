品牌系统全景：三层构造

幸福餐桌不是一次活动，而是围绕天麻产品打造的品牌系统。该系统由三层递进式的价值创造组成：

🌾

第一层：产品本质

天麻是原材料，却被定义为"幸福的物质载体"。不在功效（增强记忆、安神），而在风土故事：承德松林、四季节气、手工工艺。

🎭

第二层：行为艺术

通过季节性的"幸福餐桌"仪式上演，让消费者从旁观者变成共创者。每一次都是同一作品的变奏，积累品牌仪式资本。

💰

第三层：商业闭环

从参演凭证、衍生品复购、B端授权，到农产品提价，形成自我增强的商业飞轮。每一环都以行为艺术作为信息源和传播杠杆。

行为艺术的三重商业杠杆

🎬 杠杆一：信息生成器

每场幸福餐桌上演，产生大量高感知内容：

  • 影像： 短视频、直播、后期纪录片
  • 故事： 参与者证言、时令传说、工艺细节
  • 文化符号： "桑树下的紫色手染"、"松林午宴"

转化： 这些内容直接成为天麻产品的传播素材，用文化说服代替功效宣传。

💳 杠杆二：预售激活器

行为艺术的稀缺性和时限性，驱动提前预约：

  • 预售周期： 活动前30天开放报名，FOMO心理锁定参与者
  • 现场只体验： 不售货，引导扫码进入小程序
  • 衍生品复购： 天麻料包、桑葚酱、行为手册等

转化： 现金流锁定 + 用户数据积累 + 复购路径建立。

🤝 杠杆三：B端授权工具

将幸福餐桌的仪式脚本标准化，授权给高端餐厅和企业：

  • 品牌授权费： 按季/按年收取
  • 产品需求： 每授权一家餐厅，新增天麻料包订单
  • 品牌传播： 异地触点，全国化布局

转化： 授权费收入 + 产品销量倍增 + 品牌认知提升。

商业价值闭环：行为艺术飞轮

从一场仪式到品牌溢价的完整循环

每一次幸福餐桌的上演，都是整个系统的一次加速循环。以下是完整的价值链：

第1阶段：行为艺术上演（夏季·承德松林）

8-10人现场用餐，同步直播给千万远程观众。核心仪式：挖天麻、做手工、松树下共进幸福饭。

收入点： 参演凭证 398元/人 × 10人 = 3,980元 + 直播广告

第2阶段：高感知内容生成

纪录片、短视频、参与者证言成为"天麻文化IP"的素材库。每条视频都是天麻的情感广告。

收入点： 内容授权、品牌合作、大V联动

第3阶段：线上预售激活

直播中插入小程序链接，引导观众购买：天麻料包（228元）、桑葚酱（168元）、"行为手册"限量版（88元）。

收入点： 衍生品销售 = 200人 × 平均客单价150元 = 30,000元

第4阶段：B端品牌授权

将"幸福餐桌仪式脚本+视觉系统"授权给5家高端餐厅。每家按季缴纳授权费5,000元。同时每授权一家，新增天麻供应需求。

收入点： 授权费 25,000元 + 产品供应收入 50,000元 = 75,000元

第5阶段：农产品提价与护城河

通过行为艺术积累的品牌资本，天麻的零售价从内卷的"斤价"升级为"文化溢价"。提价幅度30%-80%（取决于形态和故事包装）。

收入点： 全年天麻销售收入提升 200%-300%

第6阶段：飞轮加速

上一个周期的利润，投入到下一次行为艺术的更大规模、更高质感。品牌资本越积累，飞轮转速越快。

收入点： 复合增长 + 长期品牌价值

单次循环预期收入模型：

参演凭证 + 衍生品 + 授权费 + 产品溢价 = 150,000-200,000元/季度

（不含品牌资本的长期价值）

未被复制的五大护城河

为什么别人做不了这个系统？

① 地理垄断

"只有幸福餐桌会在承德松林下举办"，形成地理认知独占。场景即品牌。

② 仪式资本

每一年的重复，都在加固品牌记忆。连续3年，幸福餐桌成为承德的文化节拍。

③ 用户共创

参与者不是消费者，是作品的共创者。身份认同带来的粘性远超传统营销。

④ 内容优势

行为艺术源源不断地生成"可传播的高感知内容"，零广告成本的品牌塑造。

⑤ 商业体系

从参演凭证、衍生品、授权费到产品溢价，形成完整的价值链闭环。单点突破无法复制整体效应。

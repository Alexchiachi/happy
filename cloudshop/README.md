# 無人商店雲端小舖（cloudshop/）

嘉禮慕華無人商店的線上小舖：先在網路上挑好、付款，再到店自取或寄送。網址 https://alexchiachi.github.io/happy/cloudshop/
架構與使用者介面照雲南好物（`shop/`），視覺換成嘉禮慕華品牌圖的墨綠＋米白、線描花草。頁面目前設 `noindex`。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `products.json` | **唯一的商品表**：本週預訂（名稱、截止日、取貨日）、門市資料、運費、付款資訊、商品。`demo: true` 時頁首會顯示「設計稿」提示 |
| `index.html`、`cloudshop.css`、`cloudshop.js` | 頁面、樣式、購物車與送出 |
| `images/brand.jpg`（＋`.webp`） | 開場的品牌圖（使用者提供的嘉禮慕華字標），商品照之後也放這裡（4:5、800×1000，跑 `tools/make_web_images.py`） |

中文字型共用 `shop/fonts/`（本頁已加進 `tools/subset_fonts.py`）；改了文案或商品後在專案根目錄跑 `python3 tools/subset_fonts.py`。

## 素材流程（使用者只負責丟素材）

使用者**只把照片和文字放進 Google 雲端硬碟**，下載、裁切、壓縮、文案整理、放上網頁都由 Claude 處理（同 `shop/README.md` 的做法）。

雲端硬碟資料夾「雲端小舖｜網站素材」（id `1VNBJmUTBkKhkXQ7d9Qo_OBED59ecaMl0`，與「雲南好物｜網站素材」同一層）：

| 內容 | 放什麼 |
| --- | --- |
| `雲端小舖｜商品資料表`（試算表，id `1HbasBXssS824mkX1Mev1PvU1GDN5RlpJcJDTR6eNmL0`） | 分頁「使用說明」寫給使用者看；「商品」一樣一列：區塊（本週預訂／店內常備）、狀態（上架／不上架）是下拉選單，規格與價格一行一種（`名稱｜價格`），另有分類、介紹、產地、內容量、保存、賞味期限、限量、給 Claude 的備註；「本週與門市設定」：檔名、截止日、取貨日、門市、運費、付款與 LINE 帳號 |
| `00 共用`（id `1aQrHIf53jutjreWuSUKE2HAMaNRXkh8A`） | 品牌圖、門市照片、LINE Pay 收款碼 |
| `01`、`02`、`03`… | 一樣商品一個資料夾，編號＝資料表「編號」欄。2026-10-14 建立時先放三個示範資料夾（名稱帶「示範」），使用者改成真正品名 |

資料表的三列示範（標「示範」、狀態「不上架」）在使用者填入真正商品後刪掉或覆蓋。改小地方用 Google Sheets 工具（`update_values`）直接改儲存格，id 不變。

使用者說「雲端小舖素材更新了」時：

1. 讀資料表（只收「上架」的列），列出各資料夾的新照片並下載（Drive 列表會分頁，翻到最後一頁；HEIC 用 `pillow-heif` 轉）。
2. 挑照片：檔名有「封面」的優先，沒有就挑最適合直式 4:5 的；廣告圖只裁照片區域。別人拍的照片先提醒授權。
3. 裁成 4:5、800×1000、JPG 品質約 80、250KB 以內，存 `cloudshop/images/`（檔名小寫英文加連字號），跑 `python3 tools/make_web_images.py` 產生 `.webp`。
4. 文案以資料表為準，語氣照品牌站；資料表沒寫的事實不補，不寫療效。
5. 更新 `products.json`（新商品給英文 `id`，上線後不改；`specs` 從產地、內容量、保存、賞味期限組出來；`badge: "限量"` 依限量欄），跑 `python3 tools/subset_fonts.py`，本機截圖檢查電腦版與手機版，再提交。
6. 回報：哪些商品上架、換了照片、哪些欄位還缺。

## 跟雲南好物不同的地方

- 兩個貨架：`shelf: "week"`（本週預訂，`week.deadline` 之後不能再選）與 `shelf: "always"`（店內常備）。
- 取貨方式：到店自取（免運，在取貨櫃輸入訂單編號末四碼）、宅配、7-11、全家。滿 `shipping.free` 免運。
- **還沒接後台**：送出後在前端產生訂單編號（`CS` + 日期 + 4 位亂數），完成畫面請客人「用 LINE 傳送訂單」
  （`line.me/R/oaMessage/` 帶入訂單內容）並顯示付款資訊。客人沒按傳送，訂單就不會到我們手上。
  要改成真正的訂單系統時，比照 `executive-table/worker/orders.js` 另做一支（Worker 重算金額、存 D1、寄信、後台）。
- 沒有 Email 欄、沒有送禮選項（之後需要再從 `shop/` 搬過來）。
